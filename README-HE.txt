עדכון חדר בקרה – מתקדמים v88
=============================

מה חדש:
- לכל פרופיל משתמש מוצגת הדרגה הנוכחית.
- כפתור "− הורד" להורדת דרגה אחת.
- כפתור "העלה +" להעלאת דרגה אחת.
- אפשרות לבחור ישירות דרגה 1–12.
- תמיכה בחשבון מייל עם עד שלושה פרופילים.
- השינוי נשמר ב-Firestore ומתעדכן אצל המשתמש.
- בדרגה 5 ומעלה נפתחת התקדמות למדבר.
- בהורדה מתחת לדרגה 5 המדבר ננעל מחדש.
- תיקון CSS של בקרת הדרגות ועדכון cache ל-v88.

איך לעדכן ב-GitHub:
1. פתחו את התיקייה control-room במאגר -More-mitkadmim.
2. החליפו רק את admin.js ואת index.html בקבצים שבתיקייה control-room שב-ZIP.
3. אל תמחקו את firebase-config.js הקיים.
4. לאחר העלאה המתינו דקה-שתיים ורעננו את חדר הבקרה עם Ctrl+F5.
